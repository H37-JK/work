네이버 블로그 자동 작성 사용 가이드
====================================

이 폴더의 프로그램은 바탕화면 글 폴더의 .txt 글 1개 + '작업' 폴더 사진 5장을 묶어서
네이버 블로그 글쓰기 화면에 자동으로 입력하고, 임시저장(기본) 또는 발행까지 해줘요.
(네이버 글쓰기 API는 종료돼서, 실제 크롬 창을 프로그램이 대신 조작하는 방식이에요.)


■ 1. 처음 한 번만: 준비
------------------------------------
1) 파이썬 설치
   - https://www.python.org/downloads/ 에서 "Download Python" 클릭 후 설치
   - 설치 첫 화면 아래쪽 "Add python.exe to PATH" 꼭 체크하고 Install Now

2) 이 폴더에서 [1_설치.bat] 더블클릭
   - 검은 창에서 설치가 진행되고 "Done" 이 나오면 아무 키나 눌러 닫기

3) 설정 바꾸기: naver_autopost.py 를 오른쪽 클릭 > 연결 프로그램 > 메모장
   맨 위 "설정" 부분만 고치면 돼요.
     BLOG_ID          내 블로그 아이디 (blog.naver.com/아이디)  ← 필수
     POSTS_DIR        글(.txt) 폴더 경로
     IMAGES_DIR       사진 폴더 경로 (기본: 바탕화면\작업)
     IMAGES_PER_POST  글 1개당 사진 수 (기본 10, 고정 사진 제외, 랜덤 선택)
     FIXED_IMAGE      매 글마다 항상 넣는 사진 (기본 1.png, 본문 맨 위에 항상, 옮겨지지 않음)
     FIXED_IMAGE_POSITION  고정 사진 위치 "맨앞" 또는 "맨끝" (기본 맨앞)
     MODE             "임시저장" 또는 "발행" (기본 임시저장)
     MAX_PER_DAY      하루 최대 개수 (기본 0 = 제한 없음)
     MAX_PER_RUN      한 번 실행에 최대 개수 (기본 0 = 폴더 전부)
     WAIT_MINUTES     글 사이 랜덤 대기(분) (기본 0,0 = 대기 없음)
     IMAGE_POSITION   "분산"(문단 사이 고르게) / "맨끝"(본문 끝에 모아서)
   저장(Ctrl+S) 후 닫기.

4) [2_로그인.bat] 더블클릭
   - 크롬 창이 뜨면 네이버에 직접 로그인 ('로그인 상태 유지' 체크)
   - 캡차/2단계 인증도 직접 하면 돼요
   - 로그인 끝나면 검은 창으로 돌아가서 Enter
   - 로그인 정보는 이 폴더의 chrome_profile 에 저장돼서 다음부터는 다시 안 해도 돼요.
     (로그인이 풀리면 이 단계만 다시)


■ 2. 매번 쓸 때
------------------------------------
1) 글 폴더에 .txt 글 넣기
   - 파일명 = 제목 (예: 마포구 공덕동 변기뚫는비용 및 막힘해결 업체 추천.txt)
   - 본문은 문단 사이에 빈 줄. 마침표 없는 짧은 줄은 소제목으로 보고 굵게 처리해요.

2) '작업' 폴더에 사진 넣기
   - 글마다 작업 폴더(하위 폴더 포함)에서 10장을 랜덤으로 골라요. 1.png 는 매번 맨 위 고정이에요.
     같은 사진이 다른 글에 다시 쓰일 수 있어요 (한 글 안에서는 중복 없음).
   - 사진은 옮기지 않아요.

3) [3_미리보기.bat] 더블클릭  (브라우저 안 열림, 확인용)
   - 이번에 올라갈 글 제목, 소제목, 어떤 사진이 어느 문단 뒤에 들어갈지 보여줘요.

4) [4_실행.bat] 더블클릭
   - 크롬이 열리고 자동으로 제목/본문/사진을 입력해요. 끝날 때까지 마우스/키보드 건드리지 마세요.
   - 대기 시간을 넣었다면 그동안 창은 그대로 두세요 (최소화는 괜찮아요).
   - 처리한 글은 완료목록.txt 에 기록돼서 다시 안 올라가요.
     같은 글을 다시 올리고 싶으면 완료목록.txt 에서 그 줄을 지우면 돼요.


■ 3. 처음엔 이렇게 확인하세요
------------------------------------
- MODE = "임시저장" 으로 1개만 (MAX_PER_RUN = 1) 돌려보고,
  블로그 글쓰기 > 임시저장 글에서 제목/문단/사진 위치가 괜찮은지 확인.
- 괜찮으면 MODE = "발행" 으로 바꿔서 사용.
- 사진 뒤에 글이 이상하게 붙거나 순서가 꼬이면 IMAGE_POSITION = "맨끝" 으로 바꿔보세요.


■ 4. 오류가 나면
------------------------------------
- 문제가 생기면 그 자리에서 멈추고, 오류스크린샷 폴더에 화면을 저장해요.
  그 글은 완료목록에 안 들어가고 사진도 안 옮겨져서, 원인 해결 후 다시 실행하면 그 글부터 이어서 해요.
  (단, 블로그에 반쯤 쓰인 임시저장 글이 남아있을 수 있으니 지워주세요.)
- "로그인이 풀려 있어요" → 2_로그인.bat 다시
- "~ 버튼을 못 찾았어요" → 네이버가 에디터 화면을 바꾼 경우예요. 오류스크린샷과 함께 알려주시면 고쳐드릴게요.
- 'py' 은(는) 내부 또는 외부 명령... → 파이썬 설치 때 PATH 체크를 안 한 경우. 파이썬 재설치.


■ 5. 주의 (저품질/계정 제재 예방)
------------------------------------
- 하루 2~3개 정도가 안전해요. 한 번에 수십 개 올리면 저품질(검색 누락) 위험이 커요.
- 제목 패턴이 같은 글(지역만 바뀐 글)을 연달아 올리면 유사문서로 묶일 수 있어요.
  다른 주제 글과 섞거나, 하루 간격을 두세요.
- 같은 사진을 여러 글에 재사용하지 마세요 (이 프로그램은 쓴 사진을 자동으로 옮겨요).
- 네이버는 자동화 프로그램 사용을 약관상 제한할 수 있어요. 계정 책임은 본인에게 있으니
  처음엔 임시저장으로 쓰고 직접 확인 후 발행하는 방식을 권해요.
- 실행 중 크롬 창에서 다른 작업을 하면 입력이 엉뚱한 곳으로 갈 수 있어요.


■ 6. 글 자동 생성 (5_글생성.bat)
------------------------------------
지역, 키워드, 개수를 입력하면 Claude가 글을 하나씩 새로 써서 .txt 로 저장해요.

1) 처음 한 번: API 키 준비
   - https://console.anthropic.com 가입 > Billing 에서 크레딧 충전 (최소 5달러부터)
   - API Keys > Create Key 로 키 만들기 (sk-ant- 로 시작)
   - 이 폴더의 API키.txt 를 메모장으로 열어 첫 줄을 키로 바꾸고 저장
     (키는 비밀번호처럼 다른 사람에게 보여주지 마세요)

2) [5_글생성.bat] 더블클릭 후 차례로 입력
   - 지역: 영등포구 / 운정 / 수원 영통구 ...
   - 키워드: 변기뚫는비용 / 세면대막힘 비용 / 수전교체비용 ...
   - 키워드 뒤 문구: 그냥 Enter = "및 막힘해결 업체 추천" (누수 글이면 "및 누수해결 업체 추천")
   - 개수: 10
   - 동 이름: 그냥 Enter = 그 지역의 동을 자동으로 찾아서 랜덤으로 골라요
             직접 정하려면 "당산동, 문래동, 신길동" 처럼 입력
   → 제목 예: 영등포구 당산동 변기뚫는비용 및 막힘해결 업체 추천

3) 결과
   - 이 폴더 안에 "[지역] [키워드] 글" 폴더가 생기고 거기에 저장돼요.
   - 끝나고 Y 를 누르면 자동발행 글 폴더(POSTS_DIR)가 그 폴더로 바뀌어요.
     → 3_미리보기.bat → 4_실행.bat 으로 바로 발행
   - 같은 폴더에 이미 있는 동은 다시 안 써요.

4) 참고
   - 글마다 상황(원룸, 사무실, 이사 직후, 겨울철 등)을 랜덤으로 바꿔서 서로 다른 글이 나와요.
   - 비용: 글 1개당 대략 100원 안팎 (gen_posts.py 맨 위 MODEL 을 "claude-sonnet-5-5" 로 바꾸면 절반 정도).
   - 문체 참고용 예시는 예시글.txt 예요. 마음에 드는 글로 바꿔 넣어도 돼요.
   - 자동으로 찾은 동 이름이 틀릴 수도 있으니, 발행 전에 3_미리보기로 제목을 한 번 확인하세요.


■ 7. 생성 + 바로 발행 (7_생성후바로발행.bat)
------------------------------------
- 지역, 업체명(Enter = 토일케어), 전체 개수, 동(Enter = 자동)을 입력하면
  변기 / 세면대 / 싱크대 / 수전 글을 고르게 나눠서 만들고, 끝나면 바로 블로그에 발행해요.
  예) 10개 → 주제별 2∼3개씩
- 제목: [지역] [동] 변기뚫는비용 / 세면대막힘 비용 / 싱크대막힘 비용 및 막힘해결 업체 추천,
        [지역] [동] 수전교체비용 및 누수해결 업체 추천
- 글은 "[지역] 글 날짜_시간 (업체명)" 폴더에 저장돼요. 사진은 제목에 맞는 작업\변기 등 폴더에서 골라요.
- 이미 발행한 제목(완료목록.txt)은 다시 만들지 않아요.
